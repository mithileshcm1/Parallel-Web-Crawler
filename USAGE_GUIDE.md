# Enhanced Parallel Web Crawler - Quick Start Guide

## New Features Added

### 1. Content Quality Analysis ✓
- **thin_content** flag (word_count < 100)
- **title_length** tracking
- **meta_desc_length** tracking
- Automated identification of thin content pages

### 2. SEO Health Analysis ✓
- **has_h1** / **multiple_h1** detection
- **title_too_short** / **title_too_long** validation
- **missing_meta_desc** flag
- **seo_score** (0-100) calculation based on best practices

### 3. Media Analysis ✓
- **videos** count per page
- **audio** count per page
- Correlation with load times (media-heavy vs media-light)

### 4. Performance Metrics ✓
- **response_time** per page
- Slow page detection (>2s)
- Performance correlation with media usage

### 5. Website Health Score ✓
- **health_score** (0-100) composite metric
- Weighted calculation:
  - SEO (40%)
  - Performance (30%)
  - Content Quality (20%)
  - Availability (10%)

## Usage

### Basic Crawl
```powershell
python main.py http://quotes.toscrape.com -n 8 --max-pages 50 --max-depth 2
```

### With Performance Logging
```powershell
python main.py http://quotes.toscrape.com -n 16 --max-pages 50 --max-depth 2 --log-performance perf.csv
```

### Analyze Results
```powershell
python analyze_results.py
```

## Output Files

1. **crawl_results.txt** - Basic crawl info (URL, depth, status, title)
2. **link_frequency.txt** - Most-linked URLs ranked by count
3. **analysis_results.csv** - Detailed metrics (22+ columns)
4. **broken_links.txt** - Broken URLs with status codes
5. **summary_report.txt** - Automated analysis with recommendations
6. **analysis_dashboard.png** - Visual charts (generated by analyze_results.py)

## Parallelism Architecture

All new metrics are computed **in parallel** by the analysis worker threads:

```
[Crawl Workers] → fetch pages → [Analysis Queue]
                                       ↓
[Analysis Workers] → compute all metrics (SEO, content, media, health)
                                       ↓
[Results] → CSV + Summary Report
```

This ensures zero additional latency - all new metrics are calculated during the existing analysis phase without slowing down the crawl.

## Scoring Algorithms

### SEO Score (0-100)
- Starts at 100
- -20 for missing H1
- -10 for multiple H1s
- -15 for title too short (<30 chars)
- -10 for title too long (>60 chars)
- -15 for missing meta description
- -20 for very thin content (<100 words)
- -10 for thin content (<300 words)
- -10 for missing H2s on long content

### Health Score (0-100)
- SEO Score × 0.4 (40% weight)
- Performance Score × 0.3 (30% weight)
  - >3s = 40, >2s = 60, >1s = 80, ≤1s = 100
- Content Score × 0.2 (20% weight)
  - Thin content = 0, Good content = 100
- Availability Score × 0.1 (10% weight)
  - 200 status = 100, Error = 0
